# Recycle Bin + Image Upload (PHP/MySQL)

1. Copy this folder into C:\xampp\htdocs\
2. Start Apache and MySQL in XAMPP.
3. Open http://localhost/recycle_bin_project/

No SQL import needed: config.php creates the tables (rb_technicians, rb_work_orders)
in the `recycle` database automatically. database.sql is only for reference.
